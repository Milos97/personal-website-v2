About

I'm a senior frontend developer with 6+ years in React and TypeScript, including five years of Next.js in production. Most of that was on high-traffic iGaming products, where I owned the cashier and player dashboard (deposit, withdraw, balances, transaction history) and also shipped the game lobby.

I profile with Chrome DevTools and Lighthouse, then cut cost with code splitting, lazy loading, and React Query caching. Outside work I'm into gaming and anime, so building for gaming products comes naturally.
